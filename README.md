# 🔍 User Insight Generator (사용자 인사이트 생성기)

수십 페이지의 사용성 평가 및 UX 리서치 원자료를 단 몇 초 만에 실무에 바로 투입 가능한 **'작업용 HTML 문서'**와 **'수치 집계 엑셀(.xlsx)'**로 자동 변환해 주는 클로드 스킬입니다. 

길고 지루한 분석가용 보고서가 아닙니다. 제품팀이 회의, JIRA 백로그 등록, 개발 협의에 즉시 복사-붙여넣기해서 쓸 수 있도록 철저하게 **실행(Action) 중심**으로 요약합니다.

> 📸 **[여기에 실행 화면이나 결과물 HTML 스크린샷 이미지를 추가하세요]**
> `![결과물 예시](./images/demo-screenshot.png)`

---

## ✨ 핵심 원칙 및 특징

* **팩트 기반 (Zero Hallucination):** 없는 사실(참가자 수, 인용, 지표, 과제명, 기능, 매출 영향)을 절대 지어내지 않으며, 오직 제공된 원자료에만 근거합니다.
* **관찰/해석/제안의 분리:** 본문은 실행을 위한 '이슈와 제안'에 집중하고, 복잡한 방법론과 근거 자료는 부록으로 분리하여 가독성을 극대화합니다.
* **적응형 분석 프레임워크:** 입력된 자료의 종류, 품질, 풍부함에 따라 클로드가 스스로 최적의 분석 방법과 보고서 구조를 선택합니다.
* **최적화된 포맷 출력:** 의사결정을 위한 핵심 내용은 웹에서 바로 열어볼 수 있는 `HTML`로, 정량적인 수치 집계는 데이터 가공이 편한 `.xlsx`로 완벽히 나누어 제공합니다.

## 🚀 설치 방법

이 스킬은 **Claude.ai** (웹 환경) 및 **Claude Code** (CLI 환경)에서 모두 사용할 수 있습니다.

**1. 스킬 다운로드**
* 우측 상단의 초록색 `Code` 버튼을 클릭하고 **Download ZIP**을 선택하여 파일을 다운로드한 후, 압축을 해제합니다.
* 또는 터미널에서 다음 명령어를 실행합니다: `git clone [이 리포지토리의 주소]`

**2. Claude에 스킬 업로드**
1. [Claude.ai](https://claude.ai)에 접속하여 왼쪽 하단 프로필 > `Settings(설정)`를 클릭합니다.
2. 좌측 메뉴에서 `Capabilities` > `Skills`로 이동합니다.
3. `Upload skill` 버튼을 클릭합니다.
4. 압축 해제한 폴더 내에 있는 **`user-insight-generator` 폴더 자체를 선택**하여 업로드합니다. *(주의: 최상위 폴더가 아닌 스킬 폴더를 선택해야 합니다.)*
5. 업로드 후 스킬 토글을 켜서 활성화합니다.

**3. 테스트 해보기**
설치가 완료되었다면, 리서치 원자료(텍스트, PDF, 스크립트 등)를 첨부한 뒤 아래 프롬프트를 복사해서 클로드에게 요청해 보세요!

> "첨부한 체크아웃 과정 사용성 테스트 결과를 바탕으로, User Insight Generator 스킬을 실행해서 결과 보고서와 지표 엑셀 파일을 만들어줘."

## 📁 파일 구조 및 구성 요소

클로드에 업로드되는 스킬 폴더(`user-insight-generator/`)의 내부 구조입니다.

* `SKILL.md`: 클로드를 위한 메인 지시문 (워크플로우, 근거 규칙, 적응형 분석 선택, 보고서 구조 정의)
* `references/`: 클로드가 참고하는 방법론 노트 (리서치 원칙, 분석 패턴, HTML 보고서 패턴, Maze 노트 등)
* `evals/`: 스킬 검증을 위한 테스트 프롬프트 (트리거/논트리거/엣지 케이스) 및 샘플 입력 데이터
* `examples/`: 실제 산출물 예시 (체크아웃 사용성 테스트, 가계부 인터뷰 분석 결과)

---

## 📑 출력되는 보고서 기본 구조 (HTML)

1. **이번 테스트에서 확인된 결론** (핵심 요약)
2. **우선 개선 이슈** (즉시 조치가 필요한 항목)
3. **개선안 백로그** (JIRA 등 티켓팅을 위한 표 형태)
4. **이슈별 상세 카드** (문제 / 근거 / 영향 / 제안 / 확인 방법 / 근거 수준)
5. **과제별 결과 요약**
6. **근거 부록** (접이식 UI로 깔끔하게 숨김 처리)
7. **추가 확인 필요사항**

### 📚 출처 및 방법론 참고
본 스킬은 Maze의 이해관계자 buy-in 전략, 어피니티 다이어그램, 사용성 지표, 정성 리서치 가이드에서 '핵심 원칙'만을 차용하여 설계되었습니다 (구조를 그대로 복제하지 않음). 자세한 방법론 출처는 `references/maze-methodology-notes.md` 파일에서 확인할 수 있습니다.
